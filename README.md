# 表現イメージガチャ v0.1

## Windowsで起動

このフォルダーの `index.html` をダブルクリックし、EdgeやChromeなどのブラウザで開いてください。インストール、サーバー、インターネット接続は不要です。ファイルはすべて同じフォルダーに置いてください。

最初から7項目が抽選されます。「全部ガチャる」で固定していない項目を引き直し、各行の「↻」で個別に引き直せます。「固定」を押すとその行が固定され、もう一度押すと解除されます。固定中は個別再抽選も無効です。全項目を固定すると全体再抽選も無効になります。候補が複数あれば引き直す前と違う候補になります。

「プロンプトをコピー」でコピーし、画像生成AIへ貼り付けてください。ブラウザに自動コピーを拒否された場合は文章が選択されるので、Ctrl+Cでコピーできます。

保存機能はありません。再読み込みすると抽選結果と固定がリセットされます。

## ファイルと変更箇所

| ファイル | 役割・今後の変更箇所 |
| --- | --- |
| index.html | 画面の構造・見出し |
| styles.css | 色、文字、余白、スマートフォン表示 |
| data.js | 7カテゴリすべての候補と、その視覚的特徴 |
| prompt.js | `buildPrompt(selection)`：自然な日本語文章の組み立て |
| app.js | 抽選、固定、表示更新、コピー処理 |
| README.md | 起動・編集方法 |

## 候補を追加・削除する

`data.js` をテキストエディターで開き、対象カテゴリの `items: [ ... ]` に1項目追加します。UTF-8で保存し、ブラウザを再読み込みしてください。

主役モチーフなら：

```js
{ label: "空飛ぶクラゲ" },
```

技法・画材・絵柄は、文章で使う特徴 `phrase` も記述すると自然につながります。例えば画材なら：

```js
{ label: "墨", phrase: "深い黒と淡い滲み、筆のかすれ" },
```

`phrase` を省略すると表示名を代わりに使います。構図の `phrase` は「〜してください」で終わり、句点を付けない形にします。配色の `colors` は画面上の色見本（任意）です。連想パレットは `associative: true` を設定し、`phrase` に連想される色を記述します。連想語は主役を追加する指示には使いません。

削除する場合は、対象の `{ label: ... },` 全体を削除します。各カテゴリには最低1件残してください。件数を揃える必要はありません。初期候補は12・12・12・12・12・6・6件です。

新しい候補は、既存候補と異なる視覚結果になるかを基準に選んでください。カテゴリを増やさず、平面イラストの範囲で編集する想定です。

文章の全体ルールは `prompt.js`、個々の候補の言い回しは `data.js` を変更します。機能を追加する場合は `app.js`、その操作画面は `index.html` と `styles.css` が主な変更先です。
