# 表現×画材×画風ガチャ v1.1

略称：表現ガチャ

モチーフ・表現技法・画材・配色などを組み合わせて、画像生成AI向けのプロンプトを作るランダムガチャです。意外な組み合わせから、新しい表現のアイデアを探せます。

公開先：[GitHub Pages](https://yudepan222.github.io/expression-gacha/)

このREADMEは改修版v1.1の説明です。公開先への反映状況を示すものではありません。

## 着想元

本ツールは、taneさんの[「イメージガチャ」](https://image-gacha.tane7777.chatgpt.site/)から着想を得て制作しました。表現技法や画材の組み合わせを楽しむため、独自に項目やプロンプトを設計しています。

## 起動方法

このフォルダーの `index.html` をダブルクリックし、EdgeやChromeなどのブラウザで開いてください。サイトの利用にインストール、サーバー、インターネット接続は不要です。以下の5ファイルをすべて同じフォルダーに置いてください。

- `index.html`
- `styles.css`
- `data.js`
- `prompt.js`
- `app.js`

GitHub Pagesでも動作する、外部ライブラリやバックエンドを必要としない静的サイトです。画像生成はサイト内では行わず、作成したプロンプトを別の画像生成AIで使用します。

## 基本の使い方

通常はページを開くと、7カテゴリの候補が抽選されます。

| カテゴリ | v1.1の候補数 |
| --- | ---: |
| 主役モチーフ | 40 |
| 表現技法 | 12 |
| 画材・素材 | 12 |
| 絵柄・造形方向 | 12 |
| 配色 | 17 |
| 構図 | 6 |
| 空気・雰囲気 | 6 |

- 「全部ガチャる」で、固定していないカテゴリを引き直します。
- 各行の「↻」で、そのカテゴリだけを引き直します。
- 「固定」でその行を固定し、もう一度押すと解除します。固定中は個別再抽選も無効になります。
- 全カテゴリを固定すると「全部ガチャる」も無効になります。
- 「プロンプトをコピー」でコピーし、画像生成AIに貼り付けてください。自動コピーができない場合はテキストが選択されるので、Ctrl+Cや端末のコピー操作を使用してください。

主役モチーフは抽選対象の各候補を均等確率で選ぶため、引き直しても同じ候補が出ることがあります。他のカテゴリは従来どおり、候補が複数あれば直前と異なる候補を選びます。

## 主役モチーフのお気に入り

主役モチーフの行にある星ボタン、または「モチーフのお気に入り設定」を開いた一覧の星ボタンで、登録・解除できます。登録済みは「★」と背景色で表示されます。管理パネルには登録件数が表示され、一覧はスクロールできます。

お気に入り機能は主役モチーフだけに適用されます。

「主役モチーフの抽選」で次のモードを選択できます。

| モード | 抽選対象 |
| --- | --- |
| 全部抽選 | 全モチーフ。お気に入りの有無は確率に影響しません。 |
| お気に入り抽選 | 登録済みのモチーフのみ。 |
| 非お気に入り抽選 | 未登録のモチーフのみ。 |

モードやお気に入り設定の変更、JSONインポートでは、現在のモチーフは変わりません。変更後に再抽選すると、その時点のモードに従います。固定中のモチーフも保持され、固定を解除してから再抽選できます。

### 抽選対象が0件の場合

お気に入り未登録で「お気に入り抽選」を選択した場合や、全件登録で「非お気に入り抽選」を選択した場合は、案内を表示して主役モチーフの再抽選を無効にします。自動的に別モードへ切り替えることはありません。

現在のモチーフがある場合は、その表示とプロンプトを保持します。「全部ガチャる」では、他の未固定カテゴリだけを抽選できます。

保存されたモードの対象が0件のままページを開いた場合は、主役モチーフを抽選できず、プロンプトのコピーも無効になります。お気に入り設定または抽選モードを変更し、主役モチーフを再抽選してください。

## 設定の保存と端末間の移行

お気に入りと選択中の抽選モードは、ブラウザの `localStorage` に保存します。抽選結果とカテゴリの固定状態は保存せず、再読み込み時にリセットします。

設定はブラウザ・端末間で自動同期されません。ローカルファイルと公開サイトでも、同じ設定が自動的に引き継がれるとは限りません。保存できない場合は画面に案内を表示するので、JSONを出力して設定を控えてください。

### JSONエクスポート・インポート

1. 「モチーフのお気に入り設定」を開きます。
2. 「JSONを出力」で現在の設定をテキスト欄に出力します。「JSONをコピー」では、現在の設定を出力してコピーします。ファイルのダウンロードは行いません。
3. 別の端末でサイトを開き、同じ管理パネルのJSON欄に貼り付けます。
4. 「設定を置き換えてインポート」を押します。

**インポートは現在のお気に入り設定を置き換えます。追加・統合ではありません。** JSONに抽選モードが含まれていれば、そのモードも置き換えます。含まれていなければ現在のモードを維持します。

形式は次のとおりです。

```json
{
  "version": 1,
  "favorites": ["猫", "鹿", "カラス", "喫茶店"],
  "drawMode": "favorites"
}
```

| 項目 | 内容 |
| --- | --- |
| `version` | 必須。対応するデータ形式は数値の `1` です。サイトの版番号 `1.1` とは別です。 |
| `favorites` | 必須。モチーフ名の文字列配列です。空配列 `[]` も有効です。 |
| `drawMode` | 任意。`all`（全部）、`favorites`（お気に入り）、`nonFavorites`（非お気に入り）のいずれかです。 |

存在しないモチーフ名は無視し、重複は1件にまとめます。不正なJSON、未対応のバージョン、不正な項目の型や抽選モードはエラーとして表示し、現在の設定を変更しません。

## 配色とプロンプト

配色は17種類で、各パレットに2〜4色のHEXカラーと具体的な色名を設定しています。HEXカラーは画面の色見本に、色名は生成プロンプトに使用します。

プロンプトでは、パレットを作品全体の基本配色として使い、色の使用面積や明度を自然に調整するよう指示します。濃淡や少量の差し色を許容し、表現技法に使用色数の制約がある場合はその制約を優先します。特定の配色比率は指定しません。

「秋の喫茶店」「昭和レトロ」などの配色名は色の雰囲気を示し、主役モチーフ、背景、構図、画風、時代設定を追加指定するものではありません。

## 候補を追加・削除する

今後候補を編集する場合は、`data.js` をテキストエディターで開き、対象カテゴリの `items: [ ... ]` を変更します。UTF-8で保存し、ブラウザを再読み込みしてください。

主役モチーフの例：

```js
{ label: "猫", group: "動物" },
```

`label` は短く具体的な名称とし、モチーフ間で重複させないでください。お気に入りの照合にはこの名称を使用します。名称を変更すると、以前の名称で保存されたお気に入りは現在の一覧と一致しなくなります。

`group` は管理一覧の表示用で、抽選の重み付けには使いません。省略した場合は「その他」に表示されます。お気に入り一覧と登録件数はデータから生成するため、候補の追加に合わせて更新されます。

技法・画材・絵柄は、文章で使う特徴 `phrase` も記述すると自然につながります。例えば画材なら：

```js
{ label: "墨", phrase: "深い黒と淡い滲み、筆のかすれ" },
```

`phrase` を省略すると表示名を代わりに使います。構図の `phrase` は「〜してください」で終わり、句点を付けない形にします。

配色の例：

```js
{
  label: "藍色と生成り",
  phrase: "藍色、生成り",
  colors: ["#283B65", "#EDE3C9"],
},
```

配色の `phrase` には具体的な色名、`colors` には対応する2〜4色のHEXカラーを記述します。v1.1では `associative` を使用せず、すべて同じ形式でプロンプトを生成します。

削除する場合は対象の `{ label: ... },` 全体を削除します。各カテゴリには最低1件残してください。件数を揃える必要はありません。

v1.1の改修では、「表現技法」「画材・素材」「絵柄・造形方向」「構図」「空気・雰囲気」の5カテゴリの候補データを維持しています。

文章の全体ルールは `prompt.js`、個々の候補の言い回しは `data.js` を変更します。機能は `app.js`、操作画面は `index.html` と `styles.css` が主な変更先です。
